 ## Instalação

 Clone o repositório e instale as dependências:

 ```bash
 git clone https://github.com/KeinanSZ/meu-portifolio.git
 cd meu-portifolio
 npm install
 ```

 ## Desenvolvimento

 Inicie o servidor local:

 ```bash
 npm run dev
 ```

 Depois, abra o endereço exibido pelo Vite no terminal.

 ## Validação e build

 Para executar o lint:

 ```bash
 npm run lint
 ```

 Para gerar a versão de produção:

 ```bash
 npm run build
 ```

 ## Estrutura principal

 - `src/components/`: componentes das seções Sobre, Projetos e Contato.
 - `src/assets/img/`: imagens do portfólio.
 - `src/assets/video/`: vídeo de demonstração do SQEducaPlay.
